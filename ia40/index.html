Configuración segura y recuperación

Asistente operativo basado en la configuración del puente actual. No recoge claves, no cambia Render ni modifica trabajos desde el navegador.

1. Diagnóstico real, solo lectura

Consulta el estado del backend y el resumen de cola sin escribir en PostgreSQL.

Pendiente de comprobación.

2. Shotstack: variable correcta según entorno

El puente selecciona la clave según la URL configurada. No basta con que exista una clave genérica si el endpoint apunta a producción.

Stage: configura SHOTSTACK_API_BASE con el endpoint Stage y usa SHOTSTACK_STAGE_API_KEY. El código admite SHOTSTACK_API_KEY como alternativa para Stage.

Variables de entorno del servidor — nunca en el navegador:

  • SHOTSTACK_API_BASE
  • SHOTSTACK_STAGE_API_KEY para Stage
  • SHOTSTACK_PRODUCTION_API_KEY para Producción

En producción, el puente exige SHOTSTACK_PRODUCTION_API_KEY; no reutiliza automáticamente la clave genérica, para evitar enviar una clave de Stage al endpoint de producción. No pegues ninguna clave aquí ni en el chat.

Diagnóstico específico del HTTP 403: el nombre visible del entorno en Shotstack no decide qué clave se usa; lo decide la URL configurada. Para pruebas, la URL debe terminar en /edit/stage y debe corresponder a la clave de Stage; para producción, /edit/v1 y la clave de Producción. Shotstack también indica que Stage puede devolver 403 si la cuenta no tiene al menos un crédito activo. No cambies a Producción para probar ni repitas renders hasta confirmar el emparejamiento endpoint/clave y el estado de créditos.

3. Recuperación de cola sin riesgo

  1. No reencolar los 172 trabajos QC_PENDING_REVIEW: esperan revisión editorial.
  2. No reintentar errores HTTP 403; confirmar primero endpoint y clave del mismo entorno, y comprobar que Stage tenga crédito activo.
  3. Los reintentos automáticos del puente se limitan a fallos transitorios de red, HTTP 429 y HTTP 5xx, con espera progresiva.
  4. Después de corregir la autenticación, probar un único trabajo de diagnóstico; comprobar vídeo, audio, duración y QC antes de habilitar más trabajo.
  5. Solo los trabajos que superen QC técnico y editorial pasan a aprobación humana. La publicación automática permanece desactivada.

4. Límites de esta interfaz

Esta app estática no puede cambiar variables privadas de Render de forma segura ni ejecutar escrituras en la cola. La configuración se guarda en el servidor de Render. Para habilitar operaciones reales desde esta interfaz hace falta una API de administración autenticada, con permisos mínimos y auditoría; no se deben poner tokens de Render en JavaScript.
